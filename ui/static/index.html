Where Jev Is Injected — the 4 Decision Hooks

H1 · Before prompt — Progressive Disclosure hooks/skills.py → SkillsMiddleware.wrap_model_call. Two-pass Jev choice cascade picks category → skill; only the selected skill's instructions are injected into the system prompt.
H2 · Before model — Model Routing hooks/router.py → RouterMiddleware.wrap_model_call. A probe hits typesafe/jev-router; the response model field rewrites the ModelRequest before the real call.
H3 · Before tool run — Risk Gating hooks/risk_gate.py → RiskGateMiddleware.wrap_tool_call. Static deny list first (sudo, rm -rf, git push…), then Jev noul questions (reversible / serves_task). Fail-closed to REVIEW on any Jev error.
H4 · After result — Quality Gate hooks/quality.py → QualityMiddleware.after_model. Jev choice judge (supported/unsupported/declined, accept ≥ 0.8); unsupported answers loop back to the model once.
